# Artifact Provenance

This bundle was assembled from three user-provided executed Colab notebooks:

- `LeNet_AlexNet.ipynb`
- `VGG16_CIFAR10 (1).ipynb`
- `googlenet-resnet18-cifar10-benchmark.ipynb`

The notebooks themselves are deliberately not included in this repository bundle.

CSV results were recovered from saved displayed dataframes in notebook outputs. Embedded PNG figures were extracted from notebook display outputs. Epoch logs were recovered by parsing visible stream-output lines. No model was retrained and no missing numerical result was invented.

**Important:** Jupyter/Colab sometimes truncates displayed tables and log output. When a column or epoch was not recoverable from the stored notebook output, it is omitted or left blank. If the original exported CSV/JSON artifacts are available from the Colab runtime, replace these partial output-derived artifacts with those original files before making the repository the definitive supplementary source.
